# House-Price-Prediction
This project is a regression-based machine learning model that predicts housing prices based on features such as number of rooms, lot area, location, and more. The model is trained and evaluated using the popular Ames Housing Dataset.

Dataset
The dataset used in this project can be accessed via Kaggle:
Link to the dataset: House Prices - Advanced Regression Techniques
The main dataset file used in this project is train.csv, which contains information about various house features and their respective sale prices.

Features:
GrLivArea: Above ground living area in square feet.
OverallQual: Overall material and finish quality of the house.
TotRmsAbvGrd: Total rooms above grade (does not include bathrooms).

Target:
SalePrice: The sale price of the house.

This project demonstrates the use of Linear Regression to predict house prices based on features like square footage, number of bedrooms, and bathrooms. The model provides a reasonable estimate of house prices and can be further improved by adding more features, tuning hyperparameters, or trying different algorithms.
